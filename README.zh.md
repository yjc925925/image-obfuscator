# 图片混淆器

在线打开（电脑 / 安卓 / iOS 都可以，不用下载）：https://yjc925925.github.io/img-mixer/

仓库：https://github.com/yjc925925/img-mixer

单文件离线网页工具：把图片批量混淆成无法辨认的噪声图，也能批量还原回来。
支持电脑、安卓、iOS，双击 HTML 用浏览器打开即可，全程不联网、不上传任何数据。

## 用法

1. 用浏览器打开 `图片混淆器.html`
2. 选「混淆图片」或「还原图片」
3. 填密码（可留空）
4. 选一种算法（默认「标准」，两种算法的区别见下）
5. 点选择框选图片、把图片或文件夹拖进页面、或点「选文件夹」
6. 点最下面的「开始混淆 / 开始还原」
7. 结果可以一张一张下载，也可以「打包 ZIP」一次拿走（手机上建议用 ZIP，只弹一次保存框）
8. 每张结果左边有勾选框（默认勾选，列表上方有「全选」）：底部的「一键下载」「一键删除」只处理勾选的那几张
9. 每一行右边有「预览」「下载」「删除」：预览直接看结果（点空白处或按 Esc 关闭），下载拿走单张，删除单独去掉某一张（正在处理时暂时不可用）
10. 点「下载」或「打包 ZIP」时，会先让你选**一次**文件夹（勾着「保存到文件夹」时），结果直接写进那个文件夹，之后不再逐张弹窗

还原时会自动识别用的是哪种算法，不用再选。文件名的 `.mix` 去掉就是原名；原文件名里没有 `.mix` 的，会加上 `unmix_` 前缀。

## 两种算法

**标准 · 原文件封装（默认）**

- 把原始文件本身（JPEG / PNG 的字节）加密后封进一张噪声图，还原出来的是**原文件本身，逐字节一致** —— 格式、EXIF、后缀全都回来。
- 混淆图的画布按载荷大小开，尺寸比原图小；体积约为原文件的 1.2 倍（10 MB 的照片，混淆后 12 MB 左右）。

**彻底 · 全图打散**

- 把原图像素整体打散重排，还原得到图片，画面与原图逐像素一致，但 EXIF、原始文件体积之类的信息会丢掉。
- 混淆图与原图等尺寸、纯噪声，体积按像素算：约每 100 万像素 3.5 MB，最高能到原图的 25 倍。

两种算法的结果都是 PNG 噪声图，都不能被压缩、截图或重新保存。

## 必须注意

- 混淆结果是 PNG 噪声图，**一个像素都不能动**。以下操作会让它永久无法还原：
  转成 JPG、截图、裁剪、重新压缩、用修图 App 打开后保存、用微信或 QQ 的「图片」方式发送。
- 发送时请用「文件」方式（微信：`+` → 文件；QQ：发送文件），或者先打包成 ZIP 再发。
- 密码不保存在任何地方，忘了就真的还原不出来。留空表示使用内置默认密钥：图片照样变成噪声，但任何拿到本工具的人都能一键还原，只适合防随手翻看。
- 要正经保密就设一个 8 位以上的密码，并且混淆和还原用同一个密码。
- Windows 上双击结果提示「你的 Internet 安全设置阻止打开一个或多个文件」：那是浏览器给**从本地网页下载**的文件打的「受限站点」标记，不是文件坏了。用「保存到文件夹」保存的结果没有这个标记；已经中招的文件，右键 → 属性 → 勾「解除锁定」，或者对文件夹跑一次 `Get-ChildItem -Recurse -File | Unblock-File`。
- 「透明区域填白」只在「彻底」算法下有用（它会抹掉透明通道）。「标准」算法保留原始文件，透明区域照原样保留。

## 三端打开方式

- **Windows / macOS**：双击 HTML 文件，用 Chrome 或 Edge 打开。
- **安卓**：把 HTML 存到手机，用文件管理器选「用浏览器打开」，或在 Chrome 地址栏输入 `file:///sdcard/...`。
- **iPhone / iPad**：系统没有直接打开本地网页的入口。最省事的做法是把 HTML 拖到 `app.netlify.com/drop`（或任意静态托管）拿到一个网址，用 Safari 打开后「添加到主屏幕」。页面本身不联网也能用。
- iOS 上「添加到主屏幕」后，处理结果会走 Safari 的下载，文件在「文件」App 里。

## 算法

**标准**

- 逻辑字节流 = 8 字节随机数（明文）+ 1 字节标记 + 加密区。
- 加密区开头是 64 字节头部：魔术字、版本、标志、文件名长度、原始宽高、载荷长度、载荷的 SHA-256、以及由密钥派生的 8 字节校验标签；后面跟着文件名和原始文件字节。整段用一个密钥流异或。
- 画布按载荷大小开，保持原图宽高比，两边都不小于 8 像素。

**彻底**

- 输出图比原图多 16 个像素，用来放 8 字节随机数 + 32 字节文件头（含原始宽高和校验标签）。
- 三重可逆变换：① 全图逐像素 Fisher-Yates 置换（随机流由密钥派生）② 另一路独立随机流对整幅图异或 ③ 输出图强制完全不透明，规避 canvas 预乘精度的有损问题。还原就是逆序反演。
- 混淆图是纯噪声、尺寸只多 16 像素；头部被改一个字节都会被校验发现。

两种算法共用同一套密钥派生：密钥 = SHA-256 迭代 4096 轮（密码 + 随机数），置换流与数据流用不同域标签，互不干扰。

## 限制

- 单张上限 4800 万像素、单边不超过 32000 像素。
- 批量打包 ZIP 上限约 900 MB，超了请单张下载。
- 处理在浏览器里逐张串行进行，中途可以点「开始」按钮停下。

## 目录

```
图片混淆器.html   成品（单文件，三端通用）
src/              源码
  crypto.js       SHA-256 与伪随机流
  codec.js        彻底算法：像素级打散
  codec2.js       标准算法：原文件封装
  zip.js          打包 ZIP（仅存储，不压缩）
  app.js          界面与批处理逻辑
  index.html      界面
  selftest.js     自检用例（只在开发时用，不打包进成品）
test/             测试
  core.mjs        彻底算法核心断言（Node，83 项）
  core2.mjs       标准算法核心断言（Node，177 项）
  browser.mjs     浏览器端自检（经 CDP 注入 selftest.js，22 项）
  ui.mjs          真实界面端到端（75 项：拖放、选择文件、两种算法往返、预览、保存选项、错误密码、删除）
build.mjs         把 src 内联成单文件成品
```

重新构建：`node build.mjs`（产物在 `dist/`）。

跑测试：`node test/core.mjs`、`node test/core2.mjs`；浏览器测试需要先起一个带调试端口的 Chrome（`--headless=new --remote-debugging-port=9336`），再运行 `node test/browser.mjs <成品路径>` 与 `node test/ui.mjs <成品路径>`。
